SpherePaint

Paint on 360° equirectangular images through undistorted perspective views.

Painting directly on an equirectangular (2:1) image is awkward: straight lines bend and shapes stretch towards the top and bottom. SpherePaint shows an ordinary perspective view of any direction on the sphere, lets you paint there as usual, and writes the result back into the equirectangular image with the correct distortion.

Getting started

  1. Show the panel with Settings → Dockers → SpherePaint.
  2. Open an equirectangular image (width twice the height) and select the paint layer you want to paint on.
  3. Choose a direction: click or drag in the panorama thumbnail at the top of the panel (scroll to change the field of view), type Yaw, Pitch and Field of view, or use the quick buttons Front, Right, Back, Left, Up, Down. The yellow outline shows the area the view will cover.
  4. Press Project – or just release the mouse in the thumbnail (Project when the mouse is released in the ⋯ menu is on by default). A new document called Sphere view opens.
  5. Paint in the layer Paint here. The locked layer below shows the whole image for reference.
  6. Press Write back. Only the pixels you changed are transferred; the rest of the image is untouched.
  7. Use Flat / Projection to switch between the two documents. Change the direction and press Project again to work on another part of the sphere.

360° preview

⋯ → Open 360° preview opens the SpherePaint 360° Preview docker as a floating window that you can move and resize, or dock anywhere like any Krita docker (it is also listed under Settings → Dockers). Drag in it to look around like in a 360° viewer, scroll to zoom, and release to project (when Project when the mouse is released is ticked in the ⋯ menu).

The area inside the yellow frame is exactly what Project will show; in a non-square window the panorama around it is shown dimmed. Use the thumbnail for quick, coarse aiming and the preview for fine-tuning. It is rendered from a downscaled copy of the panorama and refreshes after every write-back.

Remembered direction

Every projection stores its yaw, pitch and field of view in the panorama document. When you switch back to that panorama, or open the saved .kra file later, the panel restores them, so you continue where you left off.

Several layers

Paint here is written back to the layer you projected. You can also add more paint layers to the view, for example Trees or Sign: each visible one is written back to the panorama layer with the same name, which is created above the projected layer if it does not exist. Only what you change is transferred.

When you project, each extra layer shows what its same-named panorama layer already contains, seen from the new direction – so Trees in the view shows the trees you painted before, and you can add to them, erase or repaint. The layers carry over to every new direction. A layer you add to the view after projecting starts empty; press Project again to load its existing content. Undo last write-back covers all affected layers and removes layers it created.

Working with AI image generation

Image generators such as Stable Diffusion or Flux work best on ordinary perspective images. A Sphere view is a normal Krita document, so tools like the Krita AI Diffusion plugin can be used in it like on any image – and SpherePaint writes the result back onto the sphere.

  1. Generate a base panorama at a 2:1 size (e.g. 1536×768, then upscale) with a model or LoRA trained for 360° equirectangular images.
  2. Fix the poles: generated panoramas are often blurry or swirly straight up and down. Press Up or Down, Project, inpaint the sky or ground in the undistorted view, and Write back.
  3. Fix the seam: press Back – the left/right seam is then in the middle of the view. Inpaint across it and write back.
  4. Add details anywhere: select an area in any view and inpaint or generate there; the model sees a normal perspective image.

Generating directly into an extra layer in the view (e.g. AI) keeps the result on its own panorama layer after write-back.

Sharing as a 360° image

⋯ → Export for 360° viewers… saves the panorama (all visible layers) as a JPEG and adds Google Photo Sphere (GPano) metadata. Facebook, Google Photos, Kuula and most 360° viewers use it to show the image as an interactive panorama instead of a flat picture. Hide the guide layer before exporting if you don't want it in the image.

Cube maps

⋯ → Cube map → Export cube map… saves the panorama (all visible layers) as six square images in a folder of your choice: name_front, _right, _back, _left, _top, _bottom, as PNG for 8/16-bit images and EXR for floating point. The face size matches the panorama's pixel density.

⋯ → Cube map → Import cube map… asks for the _front image, finds the five others next to it, and creates a new panorama from them. All faces must be square, the same size and the same colour depth.

Faces are oriented as seen from the centre of the sphere: front, right, back and left are upright; the top of the top image points towards the back and the top of the bottom image towards the front. Game engines use different conventions, so some faces may need rotating or mirroring for a specific engine.

Guide layer

⋯ → Add guide layer adds a semi-transparent layer on top of the equirectangular image showing the six cube faces – FRONT, RIGHT, BACK, LEFT, TOP, BOTTOM – with their edges, a 4×4 grid and a centre cross, all correctly distorted. It helps you find your way around the sphere and is visible in the reference layer of projected views. Hide or delete it like any other layer. It needs an RGBA image with 8 or 16 bits per channel.

Keyboard shortcuts

The main commands are Krita actions, listed under Tools → Scripts: Project view, Write back to sphere, Toggle flat / projection, Undo last write-back and Add guide layer. Assign keys to them in Settings → Configure Krita → Keyboard Shortcuts (search for “SpherePaint”). They need the SpherePaint docker to be enabled.

Function keys work well, for example F7 project, F8 write back, F9 toggle, Shift+F8 undo and Shift+F7 guide layer. Avoid Alt+letter combinations: the canvas reserves Alt for Alt+click and usually swallows them.

Tips

  • Automatic view size (in the ⋯ menu, on by default) gives the view the same pixel density as the equirectangular image at its centre. Turn it off and use View size… for more detail.
  • A field of view of 60–100° gives little distortion at the edges of the view. Use a narrower field of view near the poles.
  • Only one Sphere view is kept open. Projecting again updates it, or replaces it (closing the old one) when the view size or the panorama changes.
  • If you project a new direction while the view has changes that have not been written back, SpherePaint asks whether to write them back first; otherwise they are discarded.
  • Krita's own Wrap Around Mode (W) is useful in the flat image for seamless strokes across the left/right edge.

Limitations

  • Write-back is not part of Krita's undo history. Use Undo in the panel (one step), or save before larger changes.
  • Hidden layers in the view are not written back – use them for sketches.
  • The source must be a regular paint layer. 8/16-bit integer and 16/32-bit float colour depths are supported.
